# マイルストーン達成見込み 仕様書

## 1. 概要

マイルストーンに「何が終われば達成か（対象）」を持たせ、対象の予測完了日と予定日を比べて達成見込みを出す。WBS 画面の「マイルストーン」タブで設定・確認する（`src/components/milestone/`）。

関連: [要件整理 2-3・§7.2](../plans/progress-management-analysis-requirements.md)

## 2. 対象の種類

| 種類 | 値 | 対象 | 達成の判定 | 見込み日 |
|---|---|---|---|---|
| イベント | `EVENT` | なし（顧客レビュー等） | 達成日の記録 | 出さない |
| フェーズ完了 | `PHASE` | フェーズ1つ（`phaseId`） | 達成日の記録、またはフェーズのタスクがすべて完了 | フェーズの予測完了日（Earned Schedule。[02-evm 付録「フェーズ別EVM」](./02-evm.md)）。予測できなければ予定ベース |
| タスク指定 | `TASKS` | 任意のタスク群（フェーズをまたいでよい。`milestone_task`） | 達成日の記録、または指定タスクがすべて完了 | 予定ベース |

**予定ベースの見込み日** = 未完了の対象タスクの予定終了日の最大値。予定終了日を過ぎた未完了タスクがあれば、その分は今日とする（今日より前の日付にはならない）。

## 3. 達成見込みの判定

`src/domains/milestone/milestone-forecast.ts`。日付は暦日、「今日」は JST。

1. 達成日を記録していれば **達成**（予定日との差つき）
2. イベント型: 予定日を過ぎていれば **期限超過**、そうでなければ **予定のみ**
3. 対象タスクがない（フェーズにタスクがない・対象フェーズが削除された・指定タスクの紐付けがすべて切れた）なら **対象なし**
4. 対象タスクがすべて完了なら **達成**
5. 予定日を過ぎていれば **期限超過**
6. 見込み日がなければ **予定のみ**、見込み日 ≦ 予定日なら **見込みどおり**、それより後なら **遅延見込み**（遅れ日数つき）

## 4. 紐付け

- タスク指定型の紐付けはタスク ID で持つ。WBS 同期でタスク番号が振り直されると（旧タスクは論理削除）紐付けが切れる。これは許容し、一覧に「紐付け切れ N件」と表示する
- タスクを物理削除（洗い替え同期等）すると紐付けも消える（`onDelete: Cascade`）
- 対象フェーズを削除すると `phaseId` は null になり、「フェーズ: （削除済み）」「対象なし」と表示する

## 5. 画面

- 一覧: 名前・予定日・対象（フェーズ名またはタスク指定、完了数 / 対象数、紐付け切れ）・達成見込み（見込み日または達成日、遅れ日数）・残り日数
- 作成・編集: 名前・予定日・達成の対象（イベント／フェーズ完了／タスク指定）・対象フェーズまたは対象タスク（番号・名前で絞り込み）・達成日（任意）
- データ取得: `listMilestoneForecasts`（`src/app/wbs/[id]/actions/milestone-actions.ts`）→ `MilestoneApplicationService.listMilestoneForecasts`。従来の `getMilestones`（ガント・サマリー用）は変えていない
