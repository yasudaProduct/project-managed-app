# 基準日程からのずれ 仕様書

## 1. 概要

基準（KIJUN＝ベースライン）日程に対して、現行の予定（YOTEI）日程がどれだけずれたかを示す。計画そのものの変化（Q3: 計画は変わっていないか）を、タスク単位で見えるようにする。

関連: [要件整理 2-4](../plans/progress-management-analysis-requirements.md)

## 2. スリップ日数

```
スリップ日数 = 予定終了日 − 基準終了日（暦日）
```

- 正の値は基準より遅れ（例: +3日）、負の値は前倒し（例: -2日）、0は「±0」
- 基準終了日・予定終了日のどちらかが未設定なら表示しない（「—」）
- 計算: `scheduleSlipDays`（`src/utils/schedule-slip.ts`）。表示: `ScheduleSlipBadge`（`src/components/wbs/schedule-slip-badge.tsx`）

## 3. 画面

| 画面 | 表示 |
|---|---|
| WBS のタスク一覧タブ | 「基準終了日」「ずれ」列（遅れは赤、前倒しは緑） |
| ガントチャート | クイックアクションの「基準バー表示」で、予定バーの直下に基準期間を細い灰色のバーで表示。予定バーとの左右のずれが基準からの遅れ・前倒し。マイルストーンには描かない |

- ガントの基準バーは既定で非表示。表示すると行の高さが基準バーの分だけ増える
- 基準日程はガントのデータ取得（`getGanttTasks`）でタスクの KIJUN 期間を `baselineStartDate` / `baselineEndDate` に渡す
